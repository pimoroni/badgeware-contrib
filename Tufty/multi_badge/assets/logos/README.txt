Put your logos in this folder and reference them from badge.json
(e.g. "LOGO": "assets/logos/my-logo.png").

Use transparent PNG files. The app preserves their aspect ratio and fits each
logo inside a 100x100 pixel area. If a file is missing (or "LOGO" is empty),
the profile's LOGO_LABEL text is shown as a placeholder instead.

Only example.png is tracked by git: any other logo you add here stays local,
so your organisations' logos are never published by accident.
